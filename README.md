# CarSharing

A self-hosted Progressive Web App (PWA) for managing a car-sharing cooperative. Members log trips, fuel fill-ups, and expenses per car. An annual settlement calculates what each member owes or is owed. Car owners receive a payout based on revenue generated by their vehicle.

## Getting started with demo data

```bash
git clone https://github.com/demeesterroel/CarSharing.git
cd CarSharing
npm install
npm run seed:demo     # creates data/carsharing.db with demo data
npm run dev           # http://localhost:3000
```

To seed into an isolated file (e.g. alongside a production-synced DB):

```bash
DB_PATH=./data/demo.db npm run seed:demo
DB_PATH=./data/demo.db npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

**Demo accounts** (username = password):

| Account | Role                                     |
| ------- | ---------------------------------------- |
| `admin` | Admin — manages cars, people, settlement |
| `owner` | Car owner (Car BB)                       |
| `alice` | Member — pays balance in full each year  |
| `bob`   | Member — partial payments                |
| `carol` | Member — partial payments                |

**What's populated:** dashboard with 5-year balances, trips/fuel/expenses across 3 cars, settlement 2021–2024 locked (2025 open).

To reset: delete the database in `data/<databasefile>.db` and re-run the `seed:demo` and `dev` commands.

Note : The `data/` directory is gitignored.

## Features

- **Trips** — log trips with odometer start/end, GPS location, auto-calculated cost per km
- **Fuel** — log fill-ups with receipt photo, auto-calculated price/litre
- **Expenses** — maintenance, taxes, and other car costs
- **Reservations** — car reservation calendar; optional sync with Google Calendar
- **Payments** — record settlement payments per member
- **Dashboard** — per-member annual balance (credit/debt overview) and owner payout card
- **Settlement** — two-step annual settlement: member balances → owner payouts
- **Admin** — manage members, cars, and app settings
- **Offline** — add entries offline, sync when back online (PWA)

## Local Development

### Prerequisites

- Node.js 20+
- npm

### Setup

```bash
git clone https://github.com/demeesterroel/CarSharing.git
cd CarSharing
npm install
```

Create `.env.local`:

```env
NEXT_PUBLIC_BASE_URL=http://localhost:3000
# Leave AUTH_USERNAME and AUTH_PASSWORD_HASH unset to disable login during development.
# To enable auth, set AUTH_USERNAME and a bcrypt hash for AUTH_PASSWORD_HASH.
```

Start the dev server:

```bash
npm run dev
# App runs at http://localhost:3000
```

The SQLite database is created automatically at `data/carsharing.db` on first run. Run migrations are applied automatically at startup.

### Seeding test data

If you have an export JSON file (`docs/data/car_sharing.json`), seed it:

```bash
npm run seed
```

### Running tests

```bash
npm test
```

## Self-Hosting (Docker)

The app runs as a single Docker container with SQLite on a mounted volume. Designed to sit behind [Traefik](https://traefik.io/) for HTTPS.

Required environment variables for production:

```env
AUTH_USERNAME=your-admin-username
AUTH_PASSWORD_HASH=your-bcrypt-hash   # bcrypt hash of the admin password
NEXT_PUBLIC_BASE_URL=https://your-domain
```

## Google Calendar Integration (optional)

When configured, reservations are automatically pushed to a shared Google Calendar. Car owners receive a personal invite and can confirm or decline by RSVPing directly in their calendar app — the app updates the reservation status automatically.

For full setup instructions, see **[docs/google-calendar-setup.md](docs/google-calendar-setup.md)**.
